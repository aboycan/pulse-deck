# Changelog

All notable changes to PulseDeck are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/) and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Licensing
- Copyright set to Madhu Kumar and PulseDeck contributors. Every source file now carries an
  `SPDX-License-Identifier: MIT` header.
- NOTICE.md now says clearly that PulseDeck is free of charge, with no ads, accounts or telemetry. It also says
  which licence applies to the source (MIT) and which to the installers (GPL-3.0-or-later as a whole), and adds
  trademark notices.
- THIRD_PARTY_LICENSES.md updated: PySide6-Essentials, SPDX identifiers, py7zr, dev tools, libmpv sources.
- New `licenses/` folder with the full licence texts, generated by `scripts/collect_licenses.py` and bundled in
  every installer. Builds fail if it's incomplete. Also added: a Windows installer licence page, a Debian
  `copyright` file and RPM `%license` entries.
- About dialog shows the copyright, licences and project link. Repository links point to github.com/aboycan/pulse-deck.

### Added
- `uninstall.py` (and a Start Menu "Uninstall PulseDeck" entry) for source setups: removes shortcuts, the
  `.venv`, the downloaded audio engine and, if asked, user data.

### Changed
- Depend on `PySide6-Essentials` instead of the full `PySide6` package, and install developer tools only with
  `--dev`. A source setup shrinks from ~950 MB to ~350 MB; re-running the installer removes the unused packages.
- Windows: `install.py` and `PulseDeck.pyw` replace the .bat files as the recommended way to set up and start
  PulseDeck (Smart App Control blocks downloaded .bat files). Setup now creates Start Menu, Desktop and folder
  shortcuts.

### Fixed
- Setup's package cleanup could delete Qt files shared with `PySide6-Essentials` ("DLL load failed while importing
  QtWidgets"); setup now verifies Qt loads and reinstalls Essentials when needed.
- Windows notifications were titled with the raw app ID ("io.github.pulsedeck.PulseDeck") and showed a generic
  info icon; they now say "PulseDeck" and show the album art (or the PulseDeck icon).
- Elapsed time and seek bar stayed at 0:00 during playback (live mpv properties were read from the options
  namespace). Also fixes the gapless queue accumulating duplicate entries and missing format/device info.

### Added
- One-step setup for running from source: `install.bat` / `install.sh` install Python if missing, the Python
  packages and libmpv (downloaded automatically on Windows); `run.bat` / `run.sh` launchers. Internet required
  for first-time setup.

## [0.1.0] - 2026-11-20

First public release.

### Added
- libmpv-based playback engine: MP3, FLAC, WAV, AAC/M4A, Ogg, Opus, WMA, AIFF; gapless playback,
  crossfade, speed, balance, ReplayGain, normalization, output device selection.
- 10-band graphic equalizer (31 Hz–16 kHz, ±12 dB) with preamp, auto headroom, clip-protection limiter,
  click-free gain ramping, bypass, 12 built-in presets and custom preset save/rename/delete/import/export.
- Playlist editor with drag-and-drop, sorting, search, M3U/M3U8/JSON import and export, missing-file handling.
- Session restore (playlist, track, position, volume, shuffle, repeat, equalizer).
- Music library with background recursive scanning, duplicate detection, browse by artist/album/genre/year,
  favourites, recently played, most played and recently added.
- Track information panel and safe metadata editor with original-tag backup and restore.
- Embedded and folder artwork with on-disk thumbnail cache and full-size viewer.
- Context menus for songs, playlists, albums and artists.
- Four original themes, custom accent colour, font size, compact mode, always on top, user theme files.
- System tray, notifications, global media keys, single instance, file associations.
- Installers: Windows (Inno Setup), macOS (DMG, Intel and Apple Silicon), Linux (AppImage, DEB, RPM).
- GitHub Actions CI on Windows, macOS and Linux; tagged releases publish all installers.
